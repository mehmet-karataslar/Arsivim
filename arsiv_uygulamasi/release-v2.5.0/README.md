# Arşivim v2.5.0 Release

## 📱 İndirme Bağlantıları

### Android
- **Dosya:** `Arsivim-v2.5.0-Android.apk` (45.9 MB)
- **Minimum Android sürümü:** Android 5.0 (API 21)
- **Kurulum:** APK dosyasını indirip telefonda çalıştırın

### Windows  
- **Dosya:** `Arsivim-v2.5.0-Windows.exe` (294 KB + DLL'ler)
- **Minimum Windows sürümü:** Windows 10
- **Kurulum:** Tüm dosyaları aynı klasöre çıkarıp EXE'yi çalıştırın

## ✨ v2.5.0 Yenilikleri

### 🔄 Synchronization Tab
- **Senkronizasyon sekmesi** artık hem bilgisayar hem mobilde görünür
- Ana navigasyon menüsüne eklenmiş
- Cihazlar arası belge senkronizasyonu

### 🗑️ Platform Optimizasyonu  
- **Tarayıcı özelliği** bilgisayar versiyonundan kaldırıldı
- Daha temiz ve optimize edilmiş navigation

### 🎨 UI İyileştirmeleri
- **Dropdown overflow** sorunları düzeltildi
- Tax screen'deki layout sorunları çözüldü
- Daha responsive tasarım

### 🛠️ Teknik İyileştirmeler
- **Database integrity** check geliştiridi
- Eksik tabloların otomatik oluşturulması
- **Notification service** iyileştirildi
- Reminder ve audio notification desteği

## 🚀 Kurulum Talimatları

### Windows Kurulumu:
1. Tüm dosyaları bir klasöre çıkarın
2. `Arsivim-v2.5.0-Windows.exe` dosyasını çalıştırın
3. Gerekli DLL dosyaları aynı klasörde olmalı

### Android Kurulumu:
1. `Arsivim-v2.5.0-Android.apk` dosyasını indirin
2. Telefon ayarlarından "Bilinmeyen kaynaklardan kurulum" seçeneğini açın
3. APK dosyasını çalıştırıp kurulum talimatlarını takip edin
