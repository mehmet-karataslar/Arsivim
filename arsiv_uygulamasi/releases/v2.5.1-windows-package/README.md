## 🚀 Kurulum ve Çalıştırma

### ⚡ **Hızlı Başlangıç**
1. **ZIP'i İndirin:** Tüm ZIP dosyasını bilgisayarınıza indirin
2. **Çıkartın:** ZIP'i istediğiniz klasöre çıkartın
3. **Çalıştırın:** `Arsivim-v2.5.1.exe` dosyasına çift tıklayın
4. **Hazır!** 🎉

### 📋 **Detaylı Adımlar**
1. **İndirme:**
   - Tüm ZIP dosyasını (`Arsivim-v2.5.1-Windows.zip`) indirin
   - Dosya boyutu: ~25 MB

2. **Çıkarma:**
   - ZIP'e sağ tıklayın → "Buraya çıkart" veya "Extract here"
   - Tüm dosyaların aynı klasörde olduğundan emin olun

3. **Çalıştırma:**
   - `Arsivim-v2.5.1.exe` dosyasına çift tıklayın
   - Windows Defender uyarısı çıkarsa: "Daha fazla bilgi" → "Yine de çalıştır"

## 🚨 **Sorun Giderme**

### ❌ **"Uygulama açılmıyor"**
- **Neden:** DLL dosyaları eksik veya yanlış konumda
- **Çözüm:** Tüm dosyaların aynı klasörde olduğundan emin olun

### ❌ **"Windows korumalı bilgisayarınızı korudu"**
- **Neden:** Dijital imza eksikliği
- **Çözüm:** "Daha fazla bilgi" → "Yine de çalıştır"

### ❌ **"msvcp140.dll bulunamadı"**
- **Neden:** Visual C++ Redistributable eksik
- **Çözüm:** Microsoft Visual C++ 2015-2022 Redistributable indirin

### ❌ **"Veritabanı hatası"**
- **Neden:** Klasör yazma izni yok
- **Çözüm:** Uygulamayı "Yönetici olarak çalıştır"
